FAIREX rclone

This is a personal-use OAuth application used by its owner to connect rclone on Windows to the owner's own Google Drive.

Purpose

The application authorizes rclone to access Google Drive so the owner's files can be mounted as a local Windows drive. It is not offered as a public service and has no public user accounts.

Google user data

Access to Google Drive data is used only to provide the owner's rclone file-system connection. The website itself does not receive, process, or store Google Drive files or OAuth tokens.
