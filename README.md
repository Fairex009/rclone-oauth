# FAIREX rclone OAuth Pages

Static GitHub Pages files for the personal FAIREX rclone Google OAuth app.

Expected GitHub Pages URLs after enabling Pages:

- Homepage: https://fairex009.github.io/rclone-oauth/
- Privacy policy: https://fairex009.github.io/rclone-oauth/privacy.html

Google Auth Platform values:

- App name: FAIREX rclone
- Application home page: https://fairex009.github.io/rclone-oauth/
- Application privacy policy link: https://fairex009.github.io/rclone-oauth/privacy.html
- Authorized domain: fairex009.github.io

After publishing the OAuth app from Testing to In Production, reconnect rclone once:

`C:\Data\Tools\rclone\rclone.exe config reconnect Fairex_gdrive:`
